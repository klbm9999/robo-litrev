# robo-litrev

A bot that helps you review literature in robotics and find insights faster.



## Corpus

`corpus/abstracts.md` holds the abstracts of the 500 most-cited open-access robotics papers from 2016-2026, and `corpus/manifest.csv` lists those papers with their identifiers and open-access links.
Both are generated by `scripts/fetch_top_robotics_papers.py` from the Semantic Scholar API, which needs no API key.
The script's docstring and the header of `abstracts.md` describe the query and the filters.

Regenerate the corpus:

```sh
pip install -r requirements.txt
python scripts/fetch_top_robotics_papers.py
```

Run the tests:

```sh
python -m unittest discover tests
```
